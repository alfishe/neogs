# NeoGS revision C-VS

NeoGS с возможностью установки mp3 декодеров серии VS10xx (VLSI solutions).

Добавлена поддержка следующих чипов:
- VS1001
- VS1003
- VS1011
- VS1053
- VS1063

**Внимание:** Файлы проекта подготовлены в системе PCAD2006

## Изменения в схеме NeoGS.sch (по сравнению с revision C):
- добавлен D8\* для mp3 декодеров в LQFP8 от VLSI
- добавлены shorts J2, J3 для выбора питания чипов
- добавлен DA7\* (нужно только для чипов с питанием 1.8V - VS1053, VS1063)
- у резисторов буквы номинала переведены в верхний регистр (вместо k теперь K)
- исправлены порты для некоторых цепей (например RD0..RD7 теперь отображаются как двунаправленные)
- выделены части схемы в блоки
- шрифты изменены в ttf
