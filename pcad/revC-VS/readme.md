# NeoGS revision C-VS

NeoGS с возможностью установки mp3 декодеров серии VS10xx (VLSI solutions).

Добавлена поддержка следующих чипов:
- VS1001
- VS1011
- VS1003
- VS1053
- VS1063

**Внимание:** Файлы проекта подготовлены в системе PCAD2006

## Изменения в схеме NeoGS.sch (по сравнению с revision C):
- добавлена резистивная нагрузка для чипов VS10xx
- добавлены DA1' и DA7\*' (LDO в SOT23-5) как альтернатива к DA1 и DA7 
- добавлен microSD разъем XSD1\* как альтернатива к SD разъему
- добавлен D8\* для mp3 декодеров в LQFP8 от VLSI
- добавлены shorts J2 для выбора питания чипов
- добавлен DA7\* (нужно только для VS чипов с питанием отличным от 3.3V)
- заменен X2 на классический аудио-разъем (как на TurboFMpro)
- у резисторов буквы номинала переведены в верхний регистр (вместо k теперь K)
- исправлены направления портов для цепей sd карты
- исправлены направления портов для некоторых цепей (например RD0..RD7 теперь отображаются как двунаправленные)
- выделены части схемы в блоки
- шрифты изменены в ttf 

## Изменения в схеме NeoGS.lib (по сравнению с revision C):
- добавлен элемент ME6211B (LDO SOT23-5)
- добавлен элемент MICROSD
- добавлен элемент классического аудио-разъема 
- исправлен элемент ECAPCHIP (+ вместо черточки)
- исправлен элемент ECAPCHIPB (+ вместо черточки, отверстие с метализацией)
